## Multi-Tool Platforms

All-in-one collections covering most daily dev utility needs.

- [WebUtil](https://webutil.tech) — 50+ client-side tools: JSON formatter, Base64, JWT decoder, hash generator, regex tester, UUID generator, password generator, color converter, and more. No ads, no tracking.
- [Code Beautify](https://codebeautify.org) — 100+ tools for formatting, encoding, and converting data.
- [FreeFormatter](https://freeformatter.com) — Formatters, validators, minifiers, and encoders for developers.
- [BrowserUtils](https://browserutils.dev) — 299 fast utilities for formatting, encoding, hashing, and converting. Privacy-first.
- [DevToolHere](https://devtoolhere.com) — 110+ free developer tools, all client-side.
- [StackUtils](https://stackutils.dev) — 90+ browser-based utilities. No registration, privacy-friendly.
- [IT-Tools](https://it-tools.tech) — Open-source collection of 80+ developer tools. Self-hostable.
- [DevToys](https://devtoys.app) — Desktop app for Windows/macOS with 30+ developer utilities.

## JSON & Data

- [JSON Formatter & Validator](https://webutil.tech/dev/json-formatter) — Format, validate, and beautify JSON with syntax highlighting and error detection.
- [JSON to CSV](https://webutil.tech/dev/json-to-csv) — Convert JSON arrays to CSV with nested object flattening.
- [YAML Converter](https://webutil.tech/dev/yaml-converter) — Convert between YAML and JSON with live preview.
- [XML Formatter](https://webutil.tech/dev/xml-formatter) — Format, validate, and beautify XML documents.
- [SQL Formatter](https://webutil.tech/dev/sql-formatter) — Beautify SQL queries with customizable indentation.
- [jsonlint.com](https://jsonlint.com) — JSON validator and formatter with error line highlighting.
- [CyberChef](https://gchq.github.io/CyberChef) — The "Cyber Swiss Army Knife" for data transformation.

## Encoding & Crypto

- [Base64 Encoder / Decoder](https://webutil.tech/dev/base64-encoder) — Encode and decode text and files to/from Base64.
- [URL Encoder / Decoder](https://webutil.tech/dev/url-encoder) — Encode and decode URLs and query parameters.
- [HTML Entities](https://webutil.tech/dev/html-entities) — Convert special characters to HTML entities for safe rendering.
- [Hash Generator](https://webutil.tech/dev/hash-generator) — Generate MD5, SHA-1, SHA-256, SHA-512 hashes.
- [JWT Decoder](https://webutil.tech/dev/jwt-decoder) — Decode and inspect JWT token header, payload, and signature.
- [JWT Expiration Checker](https://webutil.tech/dev/jwt-expiration-checker) — Check token expiration and inspect claims.
- [jwt.io](https://jwt.io) — JWT debugger with signature verification.
- [CyberChef](https://gchq.github.io/CyberChef) — 300+ encoding and encryption operations.

## Generators

- [Password Generator](https://webutil.tech/generate/password-generator) — Cryptographically secure random passwords with customizable options.
- [UUID Generator](https://webutil.tech/generate/uuid-generator) — Generate UUID v4 identifiers, bulk mode up to 100 at a time.
- [UUID v7 Generator](https://webutil.tech/generate/uuid-v7-generator) — Time-ordered UUID v7 identifiers for database-friendly keys.
- [Lorem Ipsum Generator](https://webutil.tech/generate/lorem-ipsum) — Generate placeholder text in paragraphs, sentences, or words.
- [QR Code Generator](https://webutil.tech/generate/qr-code-generator) — Create QR codes from text or URLs, download as SVG.
- [Wi-Fi QR Code Generator](https://webutil.tech/generate/wi-fi-qr-code-generator) — QR code for instant Wi-Fi network access.
- [Secure WPA2 Password Generator](https://webutil.tech/generate/secure-wpa2-password-generator) — Router-friendly passwords without ambiguous characters.

## Converters

- [Color Converter](https://webutil.tech/dev/color-converter) — Convert between HEX, RGB, HSL, and named CSS colors.
